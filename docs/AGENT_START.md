# Запуск работы двух участников

Откройте один репозиторий на двух компьютерах; каждому — отдельная ветка. Общие правила находятся в `AGENTS.md`, цель и приёмка — в `PROJECT_BRIEF.md`, MCP — в `docs/MCP.md`. Навыки лежат в `.agents/skills/` и не требуют копирования в личные каталоги.

## Сначала — общий контракт

Назначьте одного интегратора. Он фиксирует `contracts/openapi.yaml`, `contracts/example-recommendations-response.json`, `docs/ALGORITHMS.md` и `tests/fixtures/replenishment_scenarios.json` до независимой реализации. Минимум: импорт и качество данных, параметры/запуск расчёта, список и детали рекомендаций, редактирование заказа, утверждение и экспорт. Если реализация требует поменять поле контракта или ожидаемое число fixture, сначала обновите эти файлы и согласуйте изменение между backend и frontend.

## Задание для агента сервера

> Прочитай AGENTS.md, PROJECT_BRIEF.md, docs/ALGORITHMS.md, contracts/openapi.yaml и tests/fixtures/replenishment_scenarios.json. Используй $hackalem-import и $hackalem-replenishment. Реализуй backend и его тесты по согласованному контракту. Сначала импорт и базовый заказ, затем аномалии, stockout, сезонность и рост. Исходные данные локальные; для отсутствующих сведений нужны явные параметры и отдельные синтетические сценарии. Не меняй frontend. Предъяви команды запуска, проверки и ограничения.

## Задание для агента интерфейса

> Прочитай AGENTS.md, PROJECT_BRIEF.md, contracts/openapi.yaml и contracts/example-recommendations-response.json. Используй $hackalem-ui. Реализуй три экрана закупщика по согласованному контракту. До готовности API используй явно синтетические ответы, затем подключи сервер и проверь полный сценарий. Не вычисляй прогноз в браузере и не меняй backend. Покажи состояния ошибок, отсутствующих данных и повторного утверждения после правки.

## После интеграции

> Используй $hackalem-verify. Проверь пять обязательных требований по tests/fixtures/replenishment_scenarios.json, пользовательский путь и экспорт. Раздели доказательства на реальные данные и синтетические сценарии. Исправь выявленные дефекты в согласованной области, обнови README и сообщи, какие ограничения остаются.

Роли не запускаются автоматически от наличия файлов. Репозиторий содержит инструкции и настройки; готовность приложения подтверждается реализацией и выполненными проверками.
